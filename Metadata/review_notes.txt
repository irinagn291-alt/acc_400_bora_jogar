Bora Jogar works on iPhone and iPad with iOS or iPadOS 17.2 or later. It opens on Matchday with an empty team area and a preloaded Courts directory. Core functions use local storage and require no account.

On Matchday, tap Create your team. In Squad, add a player. In Season, create a season, then schedule a fixture from Matchday and assign it to that season. Open Match Details to select a line-up, enter a score, log a goal and mark the result final. Season shows the updated standings and player figures.

To test collaboration, use Share a copy and save the signed JSON file via the system share sheet. On a second installation, open the Matchday profile and choose Open a shared file. Respond to an active fixture, request a roster place in Squad, or submit a message in Team Chat after setting a display name. Share a return file and import it on the organiser's device to apply attendance responses and review requests or messages. Participants import a newer organiser copy to receive updates. The files contain readable JSON and are exchanged manually.

In Courts, Nearby requests location while using the app to sort by approximate distance. Search works without location access. MapKit map tiles require a connection, and court details can open Apple Maps or a listing source link. In Match Details, the calendar action opens a prefilled system editor where the reviewer can save or cancel. It does not read existing events. Match Reminders are initially off. Enabling them requests alert, sound and badge permission for local notifications. Widgets use local data, and a Live Activity countdown can be started manually within roughly eight hours of kick-off.
