Bora Jogar supports iPhone and iPad with iOS or iPadOS 17.2 or later. It opens on Matchday with no team data and a preloaded Courts directory. Core features use local storage and require no account.

Tap Create your team on Matchday, add a player in Squad, and create a season in Season. Schedule a match from Matchday and assign it to that season. Open Match Details to choose a lineup, enter a score, log a goal, and mark the result final. Check Season for the updated standings and player stats.

To test sharing, tap Share a copy and save the signed JSON file through the system share sheet. On a second installation, open the Matchday profile and tap Open a shared file. RSVP to an active match, request a roster spot in Squad, or set a display name and submit a message in Team Chat. Share a return file and import it on the organizer's device to apply RSVPs or review requests and messages. The participant imports a newer organizer copy for updates. Files contain readable JSON and are exchanged manually.

Nearby in Courts requests location while using the app to sort by approximate distance. Search remains available without location access. MapKit map tiles need a connection, and court details can open Apple Maps or the listing's source link. The calendar action opens a prefilled system event editor for saving or canceling and does not read existing events. Match Reminders start off. Turning them on requests alert, sound, and badge permission for local notifications. Widgets use local data, and the reviewer can manually start a Live Activity countdown within roughly eight hours of kickoff.
